Aim:
To study inter-process communication using anonymous pipes and implement shell command piping.

Commands Used:

gcc producer_consumer.c -o producer_consumer
./producer_consumer

gcc pipe_command.c -o pipe_command
./pipe_command

Observations:

1. Parent process acts as producer.
2. Child process acts as consumer.
3. Anonymous pipe transfers data between processes.
4. dup2() redirects standard input/output.
5. exec() executes ls and grep commands.
6. Pipe connects the output of ls -l to the input of grep ".c".

Conclusion:

Anonymous pipes provide efficient communication between related processes. Linux pipes together with fork(), dup2(), and exec() can implement shell pipelines.
