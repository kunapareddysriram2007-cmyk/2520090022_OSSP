Aim:
To implement client-server communication using Named Pipes (FIFOs) and demonstrate POSIX signal handling.

Commands Used:

mkfifo
gcc
kill

Signals Tested:

SIGINT
SIGTERM
SIGUSR1

Observations:

1. Client sends a message through FIFO.
2. Server receives and processes the message.
3. Server sends a response through another FIFO.
4. Signal handlers execute asynchronously whenever a signal is received.
5. SIGINT, SIGTERM and SIGUSR1 are successfully handled.

Conclusion:

Named Pipes provide inter-process communication between unrelated processes. POSIX signal handlers enable asynchronous event handling by responding to signals generated by the operating system or other processes.
