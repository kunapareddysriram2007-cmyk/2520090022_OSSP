Aim:
To implement command history using dynamically allocated memory and verify proper memory management.

Commands Used:

gcc skill-03.c -o skill-03
./skill-03

valgrind ./skill-03

Observations:

1. Commands are stored dynamically.
2. History command displays previous commands.
3. Dynamic memory allocation is done using malloc().
4. Memory is released using free().
5. Valgrind confirms that there are no memory leaks.
6. Buffer overflow is prevented by limiting input size.

Conclusion:

The program demonstrates command history storage, dynamic memory allocation, memory deallocation, and memory leak verification using Valgrind.
