Aim:
To split user input into tokens and generate a simple command parser.

Commands Used:

gcc skill-04.c -o skill-04
./skill-04

Observations:

1. Input is divided into tokens using whitespace delimiters.
2. strtok() separates commands and arguments.
3. Empty commands are detected.
4. The first token is treated as the command.
5. Remaining tokens are treated as arguments.
6. Parsing output helps verify command syntax.
7. Invalid or empty input is handled safely.

Conclusion:

The program demonstrates lexical analysis and simple parser logic by converting user input into tokens and identifying commands and arguments.
