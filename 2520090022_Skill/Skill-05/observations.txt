Aim:
To understand the handling of single and double quotes in shell commands.

Commands Used:

gcc skill-05.c -o skill-05
./skill-05

Observations:

1. Single quotes preserve literal text.
2. Variables inside single quotes are not expanded.
3. Double quotes preserve spaces.
4. Variables inside double quotes can be expanded by a shell.
5. Quoted strings are accepted as a single unit.
6. The program identifies both single and double quotes.

Conclusion:

The program demonstrates basic parsing of quoted strings and differentiates between single-quoted and double-quoted input.
