Aim:
To process escape sequences and execute commands using child processes.

Commands Used:

gcc skill-06.c -o skill-06
./skill-06

Observations:

1. Escape characters are detected.
2. Escaped spaces and special symbols are preserved.
3. fork() creates a child process.
4. execl() executes shell commands.
5. Parent waits for the child process using wait().
6. Execution errors are handled using perror().

Conclusion:

The program demonstrates command execution, process creation, handling of escape sequences, argument passing, and parent-child synchronization.
