Aim:
To implement environment variable expansion and built-in command execution.

Commands Used:

gcc skill-08.c -o skill-08
./skill-08

Observations:

1. Environment variables are detected using '$'.
2. Variable values are obtained using getenv().
3. Undefined variables are handled correctly.
4. Built-in commands execute within the current process.
5. Invalid commands are detected and reported.
6. Shell state is maintained until the user exits.

Conclusion:

The program demonstrates environment variable expansion and built-in command dispatch using a simple command interpreter.
