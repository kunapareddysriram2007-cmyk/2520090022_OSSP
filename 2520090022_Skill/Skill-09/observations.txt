Aim:
To implement the built-in cd command and other shell built-ins.

Commands Used:

gcc skill-09.c -o skill-09
./skill-09

Observations:

1. The current working directory is displayed in the prompt.
2. The cd command changes the working directory.
3. Invalid paths generate an error message.
4. cd - switches to the previous directory.
5. Built-in commands execute in the current process.
6. Invalid commands are handled correctly.
7. Shell state is maintained until exit.

Conclusion:

The program demonstrates directory navigation, path validation, built-in command execution, error handling, and maintenance of shell state.
