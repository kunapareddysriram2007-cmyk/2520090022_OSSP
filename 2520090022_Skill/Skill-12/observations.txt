Aim:
To implement process communication using pipes and execute connected commands.

Commands Used:

gcc skill-12.c -o skill-12
./skill-12

Observations:

1. A pipe is created using pipe().
2. Two child processes are created using fork().
3. dup2() redirects standard output and standard input.
4. ls -l writes its output to the pipe.
5. grep .c reads input from the pipe.
6. Parent closes unused file descriptors.
7. waitpid() synchronizes child process completion.
8. The pipeline executes successfully.

Conclusion:

The program demonstrates inter-process communication using pipes, stream redirection with dup2(), process synchronization, and execution of connected commands.
