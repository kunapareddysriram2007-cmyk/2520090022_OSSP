Aim:
To implement append (>>) and stderr (2>) redirection using Linux file descriptors.

Commands Used:

gcc skill-14.c -o skill-14
./skill-14

cat append.txt
cat error.txt

Observations:

1. Files are opened in append mode using O_APPEND.
2. Existing file contents are preserved.
3. Standard output is redirected using dup2().
4. Standard error is redirected to error.txt.
5. Error messages are captured successfully.
6. Streams are restored after redirection.

Conclusion:

The program demonstrates append redirection and stderr redirection using open(), dup(), dup2(), and file descriptors.
