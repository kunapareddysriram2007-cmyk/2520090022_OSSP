Aim:
To study Linux signals and implement background job recovery.

Commands Used:

gcc skill-18.c -o skill-18
./skill-18

Observations:

1. A background process is created using fork().
2. SIGSTOP suspends the running process.
3. SIGCONT resumes the stopped process.
4. The job table is updated after every state change.
5. The jobs command displays the current status.
6. All child processes are terminated before exiting.

Conclusion:

The program demonstrates signal delivery, process control, job state management, background recovery, and the use of SIGSTOP and SIGCONT in Linux.
