Aim:
To register signal handlers and implement SIGINT handling for foreground jobs.

Commands Used:

gcc skill-19.c -o skill-19
./skill-19

Observations:

1. SIGINT handler is registered using sigaction().
2. Pressing Ctrl+C generates SIGINT.
3. The shell captures SIGINT instead of terminating.
4. The signal is forwarded to the foreground child process.
5. The child process terminates correctly.
6. The shell continues running after handling the signal.

Conclusion:

The program demonstrates signal registration, SIGINT handling, forwarding signals to foreground processes, protecting the shell, and updating foreground job status.
