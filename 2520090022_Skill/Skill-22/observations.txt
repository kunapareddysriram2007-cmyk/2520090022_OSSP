Commands Used:

./skill-22
./test.sh
valgrind --leak-check=full ./skill-22

3. Valgrind reports zero memory leaks.
4. Test script automates compilation and execution.
5. Program output is verified automatically.
6. Test execution completes successfully.

Conclusion:

The program demonstrates memory leak detection, proper resource cleanup, automated testing, and report generation using Linux tools.
